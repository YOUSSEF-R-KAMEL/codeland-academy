# Codeland Academy 🎓

**Empowering the Next Generation Through Technology, Logic & Creativity.**

Codeland Academy is an online coding academy designed to help children and young learners aged **10–15** develop programming skills, logical thinking, and creativity through practical, project-based learning.

Our goal is to turn students from technology consumers into technology creators.

---

## 🎯 Project Vision

To provide an engaging and structured learning environment where young learners can:

- Develop computational and logical thinking.
- Learn programming through practical experience.
- Build real-world projects.
- Improve problem-solving and creativity.
- Track their learning progress and achievements.

## 📚 Learning Tracks

| Level | Track | Duration |
|---|---|---|
| 00 | Computer & Logic Basics | 4 Weeks |
| 01 | Scratch Game Development | 8 Weeks |
| 02 | Python Programming | 12 Weeks |
| 03 | Web Design with HTML & CSS | 12 Weeks |

Each track includes structured lessons, practical exercises, and a final project.

## 🏗️ System Architecture

The platform is designed around four main user roles:

- **Admin:** Manages the academy, users, courses, groups, payments, and reports.
- **Instructor:** Manages lessons, attendance, assignments, and student evaluations.
- **Student:** Accesses lessons, submits projects, tracks progress, and views achievements.
- **Parent:** Monitors children's progress, attendance, and payments.

## ✨ Core Features

- Role-based authentication and authorization.
- Student, parent, and instructor management.
- Course and level management.
- Group and enrollment management.
- Class scheduling and attendance tracking.
- Lesson and learning resource management.
- Assignments and project submissions.
- Student progress and evaluations.
- Badges and certificates.
- Invoices, installments, and payment tracking.
- Parent and student portals.
- Academy announcements and reports.

## 🔐 Account Management

Student and parent accounts are created and managed by the academy administration.

The platform uses role-based permissions to ensure that each user can only access the features and information they are authorized to use.

## 💳 Payment Management

The academy supports manual payment tracking:

- Full course payments.
- Monthly installment plans.
- InstaPay and other supported payment methods.
- Admin-confirmed payments.
- Invoice and remaining balance tracking.

No payment is considered confirmed until the academy administration verifies receipt.
